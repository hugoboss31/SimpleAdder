# SimpleAdder

A tiny .NET console application that asks the user for two numbers and prints their sum.

## Requirements

- .NET SDK (recommended: .NET 7+) installed. Verify with `dotnet --version`.

## Build and run

From the `SimpleAdder` folder run:

```bash
dotnet build
dotnet run --project SimpleAdder.csproj
```

Or to run without building explicitly (dotnet will build automatically):

```bash
dotnet run --project SimpleAdder.csproj
```

The program will prompt for two numbers and then display their sum.
